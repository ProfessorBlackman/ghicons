# Development Guide

Setup, commands and troubleshooting. For how the pieces fit, see [ARCHITECTURE.md](ARCHITECTURE.md).

Three rules:

1. **Never hand-edit generated output.** Fix the SVG or the generator.
2. **Generation is reproducible.** `pnpm run clean && pnpm run generate` gives byte-identical output.
3. **Indexes are rebuilt, not appended to.**

## Setup

Requires Node.js and **pnpm** (npm and yarn won't resolve the workspace). Run pnpm from the repository root.

```bash
git clone https://github.com/ProfessorBlackman/ghicons.git
cd ghicons
pnpm install
pnpm run generate     # nothing generated is committed, so this comes first
pnpm run build
```

## Commands

```bash
pnpm run validate            # check the whole collection against ICON-SPEC
pnpm run validate <file>     # check one SVG or metadata file
pnpm run generate            # all outputs; or generate:core / :react / :stories
pnpm run build               # validate → generate → compile
pnpm run build:react         # React bundle only
pnpm run clean               # delete everything generated
pnpm run dev                 # playground icon browser
pnpm run storybook           # Storybook on :6006 (build-storybook for static)
pnpm run lint
pnpm test                    # Vitest
```

## Working with icons

Add or edit `svg/<category>/<Name>.svg` following [ICON-SPEC.md](ICON-SPEC.md), then:

```bash
pnpm run validate && pnpm run generate && pnpm run dev
```

Validation covers the whole collection, not just your change — that is deliberate.

**Metadata** goes in `metadata/<category>/<Name>.json` ([rules](ICON-SPEC.md#authoring-metadata)). A `meaning` without `references` fails validation. Every icon has a meaning today, so the useful work is improving sources — e.g. replacing a single reference site with Willis, Arthur, Rattray or an institution.

**Renaming or deleting** is a breaking change. Move the metadata with the artwork, or validation flags the orphan:

```bash
git mv svg/adinkra/OldName.svg svg/adinkra/NewName.svg
git mv metadata/adinkra/OldName.json metadata/adinkra/NewName.json
pnpm run generate
```

A stale export that survives regeneration is a generator bug — report it.

## Generation

`tools/canonical.mjs` reads and optimises each SVG once into a framework-neutral object. Emitters consume only that. The React emitter rewrites the root `<svg>` with prop-driven attributes and camelCases hyphenated attributes (`fill-rule` → `fillRule`).

| Path | Generated by |
|---|---|
| `packages/core/svg/**`, `registry.json`, `index.*` | `generate:core` |
| `packages/react/src/icons/**`, `src/index.ts` | `generate:react` |
| `packages/react/stories/**` | `generate:stories` |
| `packages/react/dist/**` | `build:react` |

Generated code never appears in PRs — review the SVG and the generator.

## Packaging

Before publishing:

```bash
node tools/verify-packages.mjs
```

To inspect a tarball:

```bash
pnpm -C packages/core  pack --pack-destination /tmp
pnpm -C packages/react pack --pack-destination /tmp
```

Use `-C`, not `--filter` (`pack` isn't recursive). `--pack-destination` resolves relative to `-C`.

## Testing

Coverage is thin: the metadata contract is tested. New tooling should come with tests, ideally for pipeline invariants — every SVG yields a registry entry and component, regeneration is identical, deletions remove exports, every export renders.

## Website

`ghicons_website/` is a separate repository consuming the **published** package. To try unreleased changes, use `pnpm link` or `pnpm pack`, and undo it before committing. Commit website changes in its own repo.

## Changing the icon system

Spec, naming, registry schema or API changes affect every consumer. State the problem and approach, call out breaking changes, update validation and generation together, update ICON-SPEC.md and ARCHITECTURE.md, then regenerate, review the diff and build everything. A rule the validator doesn't enforce is only a comment.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Build fails on a missing module in `src/icons/` | `pnpm run generate` |
| Icon is cropped, off-centre or blank | `viewBox` isn't `0 0 24 24` |
| Icon is invisible or white-on-white | Hardcoded `fill`; use `currentColor` |
| Export exists for a deleted icon | `pnpm run clean && pnpm run generate`; if it persists, it's a generator bug |
| Validation fails on an icon you didn't touch | Expected — fix or flag it; don't narrow the validator |
| Storybook shows no stories | `pnpm run generate:stories` |
| React warns "Invalid DOM property" | Add the attribute to `toJsxAttributes` in `tools/generators/react.mjs` |
| Website doesn't show changes | It uses the published package; release or link locally |
| pnpm workspace errors | Run pnpm from the repo root |
