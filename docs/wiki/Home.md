# GHIcons Wiki

GHIcons gathers Ghanaian symbols — Adinkra, the currency, national emblems and more — into one standardised collection. The SVG files are the source of truth, and every package is generated from them, so **contributing an icon means contributing an SVG**.

| Package | What it is |
|---|---|
| `ghicons` | Optimised SVGs and a registry of names, categories, meanings, keywords and sources. No dependencies. |
| `@ghicons/react` | React components with TypeScript types. |
