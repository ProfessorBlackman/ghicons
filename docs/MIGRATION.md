# Migration Guides

One guide per breaking release. Guide numbers are not GHIcons versions — `MIGRATION_v2.md` is the second guide, not GHIcons `2.0`.

| You are on | Upgrading to | Guide |
|---|---|---|
| `ghicons` `0.0.x` (the React package) | `0.1.0` | [MIGRATION_v1.md](MIGRATION_v1.md) |
| `ghicons` or `@ghicons/react` `0.1.x` | `0.2.0` *(unreleased)* | [MIGRATION_v2.md](MIGRATION_v2.md) |

Check your version with `npm ls ghicons @ghicons/react`, start at the matching guide, and follow each later one in order. New installs need none of them.

Old guides are removed once nobody is on the version they migrate from; they remain in git history.
